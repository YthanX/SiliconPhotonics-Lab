SOS、SOI、SNS：差别主要在波导下面

三者都可以让气体接触上方倏逝场；真正改变泄漏、约束和可制造性的，是核心下方是否存在高折射率衬底、BOX或空气间隙。

SiSiO₂蓝宝石SWG支撑空气

SOS

Silicon on Sapphire

核心下面：直接接蓝宝石，没有SiO₂ BOX和Si handle。

2014 SOS条形/槽型波导属于这一类。衬底折射率低于Si，但仍参与下方模场约束。

SOI

Silicon on Insulator

核心下面：先是低折射率SiO₂ BOX，再是高折射率Si衬底。

M4的strip/ridge都属于SOI；BOX足够厚时可隔离Si衬底，过薄则可能发生衬底泄漏。

SNS

Suspended Nanomembrane Silicon

核心下面：局部BOX被移除，超薄Si核心下方直接是空气；SWG连接到两侧锚区。

空气上下包围使外场占比更高；SWG同时承担机械支撑与横向光学约束，但加工和可靠性更复杂。

一眼区分： SOS是“Si直接在蓝宝石上”；SOI是“Si / SiO₂ / Si三层”；SNS是“把感测区核心下方掏空，用空气和SWG把超薄Si膜悬起来”。
