# U04：M4 真实路径与长度加权 Gamma

> 状态：学习记录版（路径映射逻辑已整理；曲率传播仍属于 U05）

## 核心问题

怎样把直波导 FDE 得到的 `Gamma(W)` 映射到 GDS 路径，同时不把它误称为弯曲传播
仿真？

## 1. 离散加权

把路径划成小段，每段有宽度 `W_i` 和弧长 `Delta_s_i`。先由截面 FDE 得到
`Gamma(W_i)`，再计算：

```text
Gamma_bar = sum[ Gamma(W_i) * Delta_s_i ] / sum[ Delta_s_i ]
```

它回答“沿路径按长度平均的局部截面重叠是多少”，不回答“弯曲后真实模场仍有多少
功率留在气体区”。

## 2. 映射流程

```text
GDS/代理路径 → 读取宽度和弧长 → 插值 Gamma(W)
             → 每段 Gamma(W_i) × Delta_s_i
             → 求和并除以总长度 → Gamma_bar 与 L
```

当前代理路径总长度约 11.035456 cm，中央 3→2→3 µm 局部段约占 0.7808%。因此整体
平均值接近 3 µm 端点，但仍取决于局部长度和插值方法。

首轮路径映射结果约为：

| 分支 | `Gamma_bar` | 条件 |
|---|---:|---|
| M4-2025 | 27.9450% | 实际 2025 GDS 平面 + 70 nm strip 条件截面 |
| M4-2026 | 15.2588% | 2025 几何规律代理 + 220/90 nm rib |

数值必须与对应中心线、宽度律、截面和 `A-FDE-PATH-MAP` 一起引用。

## 3. 明确不包含

直 FDE 映射没有求解曲率导致的模场偏移、弯曲辐射、模式转换、粗糙散射或相邻圈耦合；
这些属于 U05 的 bent-FDE、EME 或 FDTD 验证范围。

## 4. 进入后处理的接口

路径映射把光学结果压缩成 `Gamma_bar + L`，再进入 Beer–Lambert、DAS/WMS 信号链。
路径长度不是 Gamma，Gamma 也不是传播透射率；传播损耗要单独建模或测量。
