# U08：综合验收与三分钟项目陈述

> 状态：学习记录版（验收框架已整理；尚未宣称通过）

## 三项实操验收

1. 从空白或个人学习副本重跑一个 FDE 模型，修改宽度并正确追踪 quasi-TE0；
2. 独立计算或核验一次 Gamma，并写清楚积分口径；
3. 诊断一个故意设置错误的模型，至少指出定义、边界、网格、模式或来源中的两项。

## 最终八问

1. FDE、bent-FDE、EME 和 FDTD 分别回答什么问题？
2. M0 的 Poynting EFR 与 M2/M4 的空气 `|E|^2` Gamma 为什么不能混用？
3. M2 为什么既要二维模式又要三维配对泄漏？
4. M4 的几何、宽度律和截面哪些来自论文，哪些来自 GDS 或假设？
5. 为什么理想 TE0 高保持率不等于整芯片高透射？
6. 氮气空白、DAS、WMS/2f 在浓度反演中分别做什么？
7. 历史 M4.6 为什么必须拆成 M4-2025 与 M4-2026？
8. 当前继续流片或真实实验最缺哪三类外部条件？

## 三分钟陈述结构

```text
研究问题（20 s）
→ M0/M2 训练了什么（30 s）
→ M4 完成了哪些公开参数复现（60 s）
→ M4.5 与双分支解决了哪些可信度问题（40 s）
→ 当前缺口与希望老师指导的下一步（30 s）
```

## 通过标准

- 八问无需看笔记即可连续回答；
- 主动区分论文事实、GDS 实测、仿真结果和合理假设；
- 不声称作者原始工程、可流片版图、全 10 cm 三维传播、真实甲烷实验或论文 LOD；
- 能给出下一项仿真的输入、求解器、输出、收敛检查和停止条件。
