# U05：M4.5 曲率、EME 与失效 FDTD

> 状态：学习记录版（证据边界已整理；未宣称整条芯片传播已验证）

## 核心问题

FDE 路径 Gamma、弯曲 FDE、EME 保模率、FDTD 端口透射和实际芯片损耗分别回答什么？

| 方法 | 主要回答 | 不能单独回答 |
|---|---|---|
| 直/弯 FDE | 局部截面或局部弯曲本征模 | 整条器件端到端透射 |
| EME | 分段模式展开和模式保持 | 粗糙、真实耦合和完整实验损耗 |
| FDTD | 有限空间/时间内的场传播与端口 | 超长器件的无偏低噪声结果 |
| 实际测量 | 芯片真实透射与气体响应 | 未测结构的局部场细节 |

## 当前有效证据

- `C-M4-CIRC` 是旧圆弧控制组，不是论文 Euler 连接器；
- `C-M45-COMP-EULER` 是依据公开端点重建的工程候选，不是作者原始 GDS；
- `W2-C2-ARCLENGTH` 是宽度候选，不是作者公开的精确 `W(s)`；
- EME 理想 TE0 保持率和 bent-FDE 路径 Gamma 只能说明各自的局部/理想问题。

理想 TE0 保持率很高，只说明该模型中的模式转换很小；它不等于包含传播损耗、弯曲
辐射、粗糙和耦合器损耗后的绝对透射率。

## 为什么保留失败 FDTD

旧中央二维 FDTD 的 raw 端口值受到长时间尾迹、弯/直窗口不一致等影响，不能作为物理
透射结论。但它仍暴露了三个重要工程问题：端口积分依赖时间窗、raw 功率未自动归一化、
弯/直比值必须使用一致的端口和收敛条件。因此应保留为“失效诊断”，而不是删除或改写。
